# Native Android APP - Popular and Top Rated Movies

This app show in a grid view the most popular and top rated movies from Movie DB site.

Lib:
* Dagger-Hilt
* Coil
* Retrofit
* Gson


Architecture: MVVM

Screens(Jetpack Compose) - ViewModel - UseCase - Repository(Remote) - API


AI Tool:
Gemini 3.6 Flash : For resolve dependencies error and improve code quality.
